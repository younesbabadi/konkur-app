# دستیار درسی کنکور — راهنمای کامل (نسخه‌ی ساده‌شده)

همه‌ی فایل‌ها الان تو **یه پوشه‌ی تخت** کنار همن — دیگه نیازی به ساختن پوشه‌ی `public` نیست.

## ساختار پروژه (باید دقیقاً همینا کنار هم باشن)
```
konkur-app/
  server.js
  package.json
  .env.example
  index.html
  README.md
```

## مرحله ۱: نصب Node.js (اگه قبلاً نصب نکردی)
از nodejs.org نسخه‌ی LTS رو دانلود و نصب کن، بعد کامپیوتر رو ری‌استارت کن.

## مرحله ۲: نصب پکیج‌ها
تو پوشه‌ی پروژه، کلیک راست → Open Terminal / Open PowerShell، بعد:
```
npm install
```
صبر کن تا یه پوشه‌ی جدید `node_modules` ساخته بشه.

## مرحله ۳: کلید API رو تنظیم کن
1. از فایل `.env.example` یه کپی بگیر و اسمشو بذار `.env`
2. `.env` رو باز کن و به‌جای `your_gemini_api_key_here` کلید واقعی خودت رو بذار
3. سیو کن

## مرحله ۴: اجرا کن
```
npm start
```
باید این پیام رو ببینی:
```
✅ سرور دستیار درسی کنکور رو پورت 3000 اجرا شد
```
**این پنجره‌ی ترمینال رو باز نگه دار.**

## مرحله ۵: تو مرورگر بازش کن
فایل `index.html` رو دیگه دابل‌کلیک نکن! به‌جاش تو مرورگر برو به:
```
http://localhost:3000
```

---

## چرا قبلاً "Failed to fetch" می‌گرفتی؟
دو تا دلیل با هم بود:
1. فایل `index.html` رو مستقیم (با دابل‌کلیک، آدرس `file:///...`) باز می‌کردی، نه از طریق سرور
2. تو فایل‌هایی که داشتی، `index.html` باید تو پوشه‌ی `public` می‌بود ولی نبود — این نسخه‌ی جدید دیگه به اون پوشه نیاز نداره، همه‌چیز رو مستقیم کنار `server.js` سرو می‌کنه

## مرحله‌ی بعدی: انتشار واقعی (Deploy)
وقتی رو `localhost:3000` همه‌چیز خوب کار کرد:
1. پروژه رو (بدون پوشه‌ی `node_modules` و بدون فایل `.env`) تو یه ریپازیتوری گیت‌هاب بذار
2. تو Render.com یا Railway.app یه Web Service جدید بساز و ریپازیتوری رو وصل کن
3. تو تنظیمات Environment Variables همون مقادیر `.env` رو دستی وارد کن (GEMINI_API_KEY و بقیه)
4. سرویس یه آدرس عمومی بهت میده که همه می‌تونن ازش استفاده کنن

## نکته‌ی امنیتی
هیچ‌وقت فایل `.env` رو جایی پابلیک (مثل گیت‌هاب عمومی) آپلود نکن.
